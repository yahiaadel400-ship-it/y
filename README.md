# نظام يحيى للمحاسبة 💼

**نظام محاسبي متكامل وشامل** يغطي جميع جوانب العمليات المحاسبية والمالية.

## 📋 المحتويات

### 🏗️ البنية الأساسية
- `database/` - قواعد البيانات (SQL و MongoDB)
- `models/` - نماذج البيانات والتحقق
- `api/` - واجهات برمجية شاملة
- `services/` - خدمات العمليات المحاسبية
- `reports/` - التقارير والتحليلات
- `config/` - ملفات الإعدادات
- `docs/` - الوثائق الشاملة

## 🏢 المميزات الرئيسية

### 1️⃣ إدارة الحسابات
- إنشاء وتحرير الحسابات
- تصنيف الحسابات (أصول، الالتزامات، رأس مال، إيرادات، مصروفات)
- رصيد الحسابات

### 2️⃣ نظام الفواتير
- فواتير البيع والشراء
- إدارة الدفعات
- الخصومات والضرائب
- متابعة الديون والمستحقات

### 3️⃣ المستندات المحاسبية
- قيود يومية
- قيود التسويات
- قيود الإقفال
- أوراق العمل

### 4️⃣ التقارير المالية
- الميزانية العمومية
- حساب الأرباح والخسائر
- تقارير التدفق النقدي
- تقارير الحركة

### 5️⃣ إدارة الضرائب
- حساب الضرائب المختلفة
- التقارير الضريبية
- الإقرارات الضريبية
- الشرائب والرسوم

### 6️⃣ إدارة المشاريع والموازنات
- إنشاء موازنات
- مقارنة الفعلي بالموازنة
- تحليل الانحرافات
- تقارير الأداء

### 7️⃣ إدارة المخزون
- تتبع الأصناف
- حركات المخزون (إدخال، إخراج، تحويل)
- تقويم المخزون
- التنبيهات عند نقص الكميات

### 8️⃣ نظام العملاء والموردين
- إدارة العملاء
- إدارة الموردين
- ديون العملاء
- مستحقات الموردين

### 9️⃣ نظام الأمان والصلاحيات

- تسجيل العمليات (Audit Trail)
- نظام المستخدمين
- تشفير البيانات الحساسة

### 🔟 الأرشفة والتصنيف
- تصنيف المستندات
- أرشفة آمنة
- البحث السريع
- النسخ الاحتياطية

## 🛠️ التكنولوجيا المستخدمة

### Backend
- **Python 3.9+** مع FastAPI
- **SQLAlchemy** لإدارة قاعدة البيانات
- **Pydantic** للتحقق من البيانات

### قواعد البيانات
- **PostgreSQL** / **MySQL** للبيانات العلائقية
- **MongoDB** للبيانات غير المنتظمة

### Frontend (إذا لزم الأمر)
- React.js / Vue.js
- Tailwind CSS
- Chart.js للرسوم البيانية

### أدوات أخرى
- **Celery** للعمليات المجدولة
- **Redis** للتخزين المؤقت
- **JWT** للمصادقة

## 📦 البدء السريع

### التثبيت
```bash
# استنساخ المستودع
git clone https://github.com/yahiaadel400-ship-it/y.git
cd y

# إنشاء بيئة افتراضية
python -m venv venv
source venv/bin/activate  # على Windows: venv\Scripts\activate

# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل قاعدة البيانات
alembic upgrade head

# بدء التطبيق
uvicorn main:app --reload
```
